## 1. [FIXED — R-25, Hard Gate] Body text fails WCAG AA contrast on soft-grey sections

`text-muted` (`#737373`) is used directly on `bg-soft` (`#f5f5f5`) backgrounds. Measured ratio: **4.35:1**, below the 4.5:1 AA minimum for normal text.

Affected (label + intro paragraph in each `bg-soft` section):
- `fitur` section — line 408 (`fitur.label`), line 410 (`fitur.sub`)
- `cocok` section — line 498 (`cocok.label`), line 500 (`cocok.sub`)
- `dukungan` section — line 575 (`dukungan.label`), line 577 (`dukungan.sub`)
- `kontak` section — line 679 (`kontak.label`), line 681 (`kontak.sub`)

Same `text-muted` on plain white (`#ffffff`) passes fine (4.74:1) — this only breaks on the soft-grey sections.

**Fix applied:** added `mutedSoft: "#666666"` to the Tailwind color config (5.27:1 on `#f5f5f5`) and switched the 8 affected elements from `text-muted` to `text-mutedSoft`. `text-muted` on plain white is untouched. Verified visually in-browser.

## 2. [FIXED — R-25, Hard Gate] Form placeholder text is very low contrast

`.field::placeholder { color: #a3a3a3; }` on white background measures **2.52:1** — well under AA. The actual `<label>` text uses `text-muted` (#737373, passes at 4.74:1), so this only affects the placeholder hint inside empty inputs, but placeholders are still text under WCAG 1.4.3.

**Fix applied:** `.field::placeholder` color changed from `#a3a3a3` to `#707070` (4.95:1 on white). Verified visually in-browser.

## 4. [CLOSED — not a defect] Hero entrance animation appeared slow in this session

Re-tested with direct instrumentation (`performance.getEntriesByType('navigation')`, `document.hidden`, live opacity polling). Root cause confirmed: `window.onload` fires fast (~1.4s), but the automated browser tab was `hidden`/unfocused for most of the session, and Chrome throttles `requestAnimationFrame` (what GSAP's timeline runs on) in hidden tabs. Hero opacity was still `0` after 28s while the tab was hidden, then jumped to `1` immediately once the tab regained focus. This is an artifact of the automation tooling, not the page. A real visitor's active tab is focused by definition, so the entrance plays at its coded ~1.5-2s. No code change made.
